# monday in the news — office screens

Live, auto-rotating press-coverage deck for office screens.

- `index.html` — the self-contained slideshow (open fullscreen on a screen).
- Rebuilt weekly by the Cowork "refresh-news-screens" task; the new file is copied here and committed.

## Publish (one-time)
1. Push this folder to a new GitHub repo (in Cursor: Publish/▲ Push).
2. In Netlify: **Add new site → Import from GitHub** → pick this repo.
   Build command: empty. Publish directory: `.`  (root).
3. Netlify gives you a URL — put it on the screens. Every push auto-redeploys.
